# for Lizu 🍫

A small website: a walk with two puppies, a treat-catching game and a pink calculator.

## Change the words
Open `script.js`. Everything she reads is in the block at the top marked **EDIT HERE**.

## Put it on GitHub Pages (free)
1. Go to https://github.com/new, give the repo a name (e.g. `for-lizu`), set it to **Public**, and click **Create repository**.
2. On the new repo page, click **uploading an existing file** and drag in `index.html`, `style.css` and `script.js`. Click **Commit changes**.
3. Go to **Settings → Pages**. Under "Branch", pick `main` and `/ (root)`, then click **Save**.
4. Wait about a minute and refresh. The link appears at the top, e.g. `https://YOUR-USERNAME.github.io/for-lizu/`.
5. Open the link on your phone and check it, then write it on the paper 🐾

Tip: anyone with the link can see the page, so keep the repo name and the text to things you're comfortable being public.
